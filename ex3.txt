PART D
    1. Create a directory permissions, inside that directory create three files: secret.txt, shared.txt, public.txt. Set the following permissions using octal notation:
        nguyen-the-dang@nguyen-the-dang:~/ex3$ mkdir permissions
        nguyen-the-dang@nguyen-the-dang:~/ex3$ cd permissions/
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ vim secret.txt
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ vim shared.txt
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ vim public.txt

    secret.txt → owner can read/write, no one else has any access.
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ chmod 600 secret.txt 
    
    shared.txt → owner and group can read/write, others can only read.
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ chmod 664 shared.txt 
    
    public.txt → everyone can read, write, and execute.
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ chmod 777 secret.txt 


    2. Check your current umask value, create a new file (any file), run ls -l and explain why that new file has that permission as you saw from the ls -l command
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ umask
        0002
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ touch newfile.txt
        nguyen-the-dang@nguyen-the-dang:~/ex3/permissions$ ls -l
        total 0
        -rw-rw-r-- 1 nguyen-the-dang nguyen-the-dang 0 Sep  6 11:19 newfile.txt
        -rw-rw-r-- 1 nguyen-the-dang nguyen-the-dang 0 Sep  6 11:02 public.txt
        -rwxrwxrwx 1 nguyen-the-dang nguyen-the-dang 0 Sep  6 11:00 secret.txt
        -rw-rw-r-- 1 nguyen-the-dang nguyen-the-dang 0 Sep  6 11:02 shared.txt
    
        Explain:
        Bởi vì quyền ban đầu của file trong Linux là 666 (tương đương với rw-rw-rw) và không tự động cấp quyền thực thi (x) cho file mới. 
        Mà umask của em là 0002 (000 000 010) và kết quả của lệnh ls -l là -rw-rw-r-- , do đó mà owner và group có quyền đọc/ghi, còn others chỉ có quyền đọc và bị loại bỏ quyền ghi.
        real permission = default permission - umask permission
                        = (110 110 110) - (000 000 010)
                        = (110 110 100) (-rw-rw-r--)
